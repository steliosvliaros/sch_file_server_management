# SOP: SCH Portfolio Register

## File
`03_portfolio_register_v1_20260417.html`

## Purpose
Review and manage portfolio-level assets, companies, and project summaries across the SCH file server.

## Usage
1. Open the HTML file in a browser.
2. Grant folder access when prompted so the app can read the portfolio data sources.
3. Use the portfolio filters and search controls to review the current register.
4. Inspect portfolio records for company, asset, and contract status.

## Notes
- This app is a read-oriented portfolio dashboard for high-level review.
- It helps stakeholders verify that company and asset master data are aligned before generating file names or routes.
- The portfolio register does not directly produce canonical filenames, but it supports governance and review workflows.
