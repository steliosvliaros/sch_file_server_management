# SOP: SCH Payment Priority Board

## File
`05_payment_priority_board_v1_20260417.html`

## Purpose
Review payment priority, job status, and budget/actual comparisons for SCH payments and contracts.

## Usage
1. Open the HTML file in a browser.
2. Grant folder access when prompted so the app can load payment config and job data.
3. Review the dashboard panels and charts for payment health and upcoming priority actions.
4. Use the filters to focus on specific payment categories, asset groups, or due dates.
5. Save any updates back to `payment_priority_jobs.json` if the app allows editing in the working folder.

## Notes
- The payment board is driven by `payment_priority_config.json` and `payment_priority_jobs.json`.
- It supports site-level payment tracking and priority review, but it does not directly change file naming policy.
- Use it to align payment workflows with project and contract filing disciplines.
